# Ứng dụng Home Assistant: Rạng Đông Key Helper

Phiên bản **0.2.0** đăng nhập tài khoản Rạng Đông qua cloud và chuyển local key
vào tích hợp **Rạng Đông Smart 0.2.5**, không cần điện thoại Android/root hoặc
Tuya IoT project. Giao diện Ingress chỉ dành cho quản trị viên; key luôn được
che trên giao diện. APK do người dùng tải lên riêng, không nằm trong image.

![Hỗ trợ kiến trúc aarch64][aarch64-shield]
![Hỗ trợ kiến trúc amd64][amd64-shield]

Android root/ADB chỉ là phương án bổ sung, không bắt buộc với chế độ cloud.
