# Changelog

## 0.1.0 - 2026-09-04

- Add an administrator-only Home Assistant Ingress page.
- Verify the Ingress user's administrator group through the Home Assistant WebSocket API.
- Pair and connect to Android Wireless debugging over ADB.
- Download a pinned Frida server from the official release and verify SHA-256.
- Start Frida through the user's root manager only for the active operation.
- Support an ephemeral phone/password login through the SDK inside the original Rạng Đông app.
- Collect, validate and import local keys into the authenticated integration bridge.
- Activate and immediately abort a temporary integration flow when the bridge has not been registered yet.
- Redact local keys from the UI and avoid logging account credentials or raw keys.
